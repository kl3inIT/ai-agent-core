## v1.2.0 Requirements — Outcomes

### Chat Observability & UX (Phase 15) — DELIVERED

- [x] **SURF-11**: A `SIDEBAR` / right-sidebar chat surface beside `FULL_ROUTE` and `HEADER_BUTTON`, mounting the shared `ChatPanelFragment`, participating in `AiUiSettings` enabled-surface controls, preserving `AiChatSessionState` continuity; no separate chat backend/memory/fragment. — **Validated, Phase 15**
- [x] **OBS-01**: Ephemeral streaming-status line in a sibling slot, KIND-keyed, clears on finalization, never concatenated into the answer, never shows internal `@Tool`/entity names. — **Validated, Phase 15**
- [x] **OBS-02**: Collapsed-by-default per-turn "what the agent did — N steps, total ms" disclosure (humanized label-only steps, per-step timing, error/rollback indication); hidden for zero-tool turns. *(The `AiAuditEventListView?runId=` deep-link clause was descoped per `15-SPEC.md` — disclosure is label-only.)* — **Validated (adjusted), Phase 15**
- [x] **OBS-04**: Driven by the existing `StreamingEvent` flux + `AiAuditEvent` tree — no new persisted "turn" entity, no parallel state store; per-turn detail does not accumulate unbounded in `AiChatSessionState`; new labels use `msg://` keys in all locale bundles. — **Validated, Phase 15**

### Admin Settings — Model Picker & Config-Knob Migration (Phase 16) — DELIVERED

- [x] **MODEL-01**: Chat-model field becomes a `ComboBox` from a configurable curated catalog of self-hostable open-weights slugs (default marked); selecting writes the free-text `model` value in the active `AiParameters` profile. — **Validated, Phase 16**
- [x] **MODEL-02**: Admin can enter a custom model name (escape hatch); validity checked at first use with a clear error, not at save time. — **Validated, Phase 16**
- [x] **MODEL-03**: Model selection is admin-only; chosen model flows to per-request `ChatOptions`; new labels use `msg://` keys in all locale bundles. — **Validated, Phase 16**
- [x] **CFG-01**: Tier-1 runtime knobs (RAG top-k / similarity threshold / task-file token budget / TTL / model picker) editable in the admin UI, read fresh each turn, effective next turn without restart, via the `AiUiSettingsResolver` read-through; strict `default-params.yaml` seed stays strict. — **Validated, Phase 16**
- [x] **CFG-02**: Boot-time `@ConditionalOnProperty` toggles shown read-only with "property only — requires restart"; secrets `*.api-key` never editable/displayed (at most "configured: yes/no"); documented three-tier taxonomy classifies every audited knob. — **Validated, Phase 16**
- [x] **CFG-03**: New editable settings persisted as `AiParameters`/`AiUiSettings` fields + `agentstore` Liquibase changelog + bean-validation + all-locale labels; `AiSettingsChangedEvent` published so settings caches evict within one turn. — **Validated, Phase 16**

### Mutation Internals Hardening (Phase 17) — DELIVERED

- [x] **MUT-15**: Fail-closed gate sequence extracted into one canonical `MutationGateChain`; the five mutation tools become thin adapters; source-level invariant test locks gate order; the chain carries no `@Transactional` (only `MutationSaveExecutor.save` does). — **Validated, Phase 17**
- [x] **MUT-16**: To-one FK references batch-loaded via one **constrained** `DataManager.load(...).ids(...)` per target class (never `UnconstrainedDataManager`/raw JPQL). — **Validated, Phase 17**
- [x] **MUT-17**: Related-write metadata resolution memoized (immutable Jmix metamodel; no eviction). — **Validated, Phase 17**
- [x] **MUT-18**: Byte-for-byte behavior identical to v1.1; Phase 9/10/11 mutation suites pass unchanged + default-config zero-mutation-callback boot test passes. — **Validated (parity HOLDS), Phase 17**

### AI-Runtime Performance Pass (Phase 18) — DELIVERED

- [x] **PERF-01**: Per-turn (`RunContext`) memoization of `getReadableSchema()` / readable-entity metadata / `AccessManager` decisions / `LlmExposurePolicy` resolution; nothing user/role/exposure-sensitive reused across turns/users. — **Validated, Phase 18**
- [x] **PERF-02**: Longer-lived memoization of pure-metadata derivations + the exposure denylist, evicted on `LlmExposureChangedEvent`; `AccessManager` remains authoritative. — **Validated, Phase 18**
- [x] **PERF-03**: RAG `Filter.Expression` built once per retrieval; clauses preserved verbatim; existing `RetrievalFilterBuilder` denylist test passes unchanged. — **Validated, Phase 18**
- [x] **PERF-04**: Task-file `Media` encoded/resolved once per `(conversationId, taskFileId)` per turn; prompt/context not re-serialized within a turn; FK batch-loading (shared with MUT-16) in effect. — **Validated, Phase 18**
- [x] **PERF-05**: No benchmark harness / admin-screen perf; each optimization ships a checkable proxy; existing suites pass unchanged (865 tests green). — **Validated, Phase 18**

### Testing & Safety (cross-cutting)

- [x] **TEST-19**: Chat-observability leak test — `ObservabilityLeakTest` reuses the Phase 9 leak-guard pattern packs at the UI layer. — **Validated, Phase 15 (15-05)**
- [x] **TEST-20**: Curated-model allowlist test — every model id in the dropdown is on the self-hostable open-weights allowlist. — **Validated, Phase 16 (16-03)**
- [x] **SEC-08**: Config-knob secret denylist — no `*.api-key`/secret surfaced as editable/displayed; boot-time toggles not runtime-editable. — **Validated, Phase 16 (16-06)**
