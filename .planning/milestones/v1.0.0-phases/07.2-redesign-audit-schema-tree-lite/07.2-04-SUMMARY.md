# Phase 07.2 Plan 04: AiAuditEvent List + Detail Redesign Summary

**One-liner:** Full Flow UI redesign of the audit admin view — tree-rendered list via Jmix `<treeDataGrid>` + `@Composition` fetch plan, renamed to `AiAgent_AiAuditEvent.list/.detailDialog`, with retrieval columns exposed in the detail dialog.

## Resolved A4 (treeDataGrid element)

`<treeDataGrid hierarchyProperty="children">` is natively supported in Jmix 2.8 Flow UI. Verified by extracting `layout.xsd` from `jmix-flowui-2.8.1.jar`:

```
3416:    <xs:complexType name="treeDataGridComponent">
3419:        <xs:attribute name="hierarchyProperty" type="xs:string" use="required"/>
5540:        <xs:element name="treeDataGrid" type="treeDataGridComponent"/>
```

`treeDataGridComponent` extends `dataGridComponent`, so inherited `<actions>`, `<columns>`, `grdexp_excelExport`/`grdexp_jsonExport` actions, and the `@Supply` renderer wiring from the previous list view carry over verbatim.
