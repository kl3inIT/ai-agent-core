# Phase 7.1 Plan 06: Rewrite Phase-7 Chat Tests for Vaadin Messages Pipeline — Summary

One-liner: Rewrote `ChatViewStreamTest` + `ChatViewStopTest` from their 07-07b bodies onto the Phase 7.1 architecture — the stream test drives the `ChatService.stream → StreamEventRenderer.renderStreamEvent → markdown` contract directly, and the Stop test swaps bare `Disposable.dispose()` assertions for a behavioural `CancellationRegistry.cancel(runId)` verification plus a source-grep sentinel that fails build if the Fragment ever reintroduces the bypass path D-04 forbids.

## Test Methods Written

### `ChatViewStreamTest` (UI-01)

1. **`stream_emitsEventsInOrder_renderedMarkdownConcatenates`** — Mocks `ChatService.stream` to emit `Content("Hello ")`, `Content("world")`, `ToolCall(find_records, {})`, `ToolResult(SUCCESS, "3 rows")`, `Final(...)`. Pipes each event through `StreamEventRenderer.renderStreamEvent(evt, labels, state)` via `Flux.toStream()` and accumulates into a `StringBuilder`. Asserts the output starts with `"Hello world"`, contains `"**find_records**"`, contains `"done"` (SUCCESS label), and contains `"3 rows"`.

2. **`stream_citations_firstEmitsSourcesHeader_subsequentOnlyBullet`** — Drives the first-of-turn citation gate. Emits `Content("answer")`, two `Citation` events with distinct fixed UUIDs. Collects each renderer output into `List<String>` of fragments (not concatenated) so the first-vs-subsequent header contract is asserted per-event: fragment\[1] contains `**Sources**` + deep-link `/ai-agent/knowledge?documentId=<docA-uuid>`; fragment\[2] does NOT contain `**Sources**` but does contain the deep-link to docB. Locks A-03 deep-link format.

### `ChatViewStopTest` (UI-02)

1. **`stopClick_callsRegistryCancel_withPreAllocatedRunId`** — Behavioural. Creates `Mockito.spy(new CancellationRegistry())`, registers a mocked `Disposable` against a `runId`, calls `registry.cancel(runId)` (simulating the Fragment's `onStopButtonClick`). Verifies `cancel(runId)` was invoked on the registry AND that the registered `Disposable.dispose()` fired downstream — proving the audit-carrying chain Plan 03 wired.

2. **`stopClick_doesNotBypassRegistry_neverCallsDisposableDirectly`** — Source-grep sentinel. Reads `ChatPanelFragment.java` from disk and counts occurrences:
   - `activeStream.dispose()` ≤ 1 (D-04 allowance: onDetach fallback only when `activeRunId == null`)
   - `cancellationRegistry.cancel(` ≥ 2 (at minimum the Stop click + onDetach-with-runId branches)

   Plan 03 shows 4 total `cancel(` call sites (Stop, onDetach, setConversationId mid-stream, startNewChat mid-stream); the `>= 2` floor is the conservative enforcement bar.

## Path-Resolution Approach (Plan Decision Executed)

The plan pre-flagged that the source-grep path might need adjustment at execute time. The chosen approach: **relative path first, `user.dir` fallback second**:

```java
Path primary = Paths.get("src/main/java/com/vn/agent/view/chat/fragment/ChatPanelFragment.java");
if (Files.exists(primary)) { ... }
Path fallback = Paths.get(System.getProperty("user.dir"))
    .resolve("ai-agent/ai-agent/src/main/java/com/vn/agent/view/chat/fragment/ChatPanelFragment.java");
```

Gradle's `:ai-agent:ai-agent:test` runs with CWD `ai-agent/ai-agent/` so the primary path resolves directly. The fallback handles IDE runs that default to repo root CWD. Neither path needed the classpath-URL approach — kept the test simple.
