Create utility `@Component` `LiteralCoercer`. **Responsibility:** coerce a raw JSON-deserialized value (`Object`) to the Java type expected by a `MetaProperty`, throwing `ToolUserError` with a descriptive DTO on failure.

**Coercion rules (D-07):**
- Association attribute (`range.isClass()`): value must be a String; call `UUID.fromString(String)`. Failure → `ToolUserError("invalid_literal", "expected UUID id for " + property, List.of("UUID string, e.g. '4f2b...'"))`.
- Enum attribute (`range.isEnum()`): value must be a String; call `Enum.valueOf(enumClass, value)`. Failure → `ToolUserError("invalid_literal", "unknown enum constant", List.of(/* enum.name() list */))`.
- Datatype attribute (`range.isDatatype()`): dispatch on `datatype.getJavaClass()`:
  - `String.class` → String.valueOf(value) (never fails except on null if operator is not IS_SET).
  - `UUID.class` → `UUID.fromString(value.toString())`.
  - `Boolean.class` → accept `Boolean` or String `"true"/"false"` via `Boolean.parseBoolean`; anything else → error.
  - `Integer.class`, `Long.class`, `Short.class` → try `Number.intValue/longValue/shortValue` if already a Number, else `Integer.parseInt`/`Long.parseLong`/`Short.parseShort` on `toString()`.
  - `BigDecimal.class` → `new BigDecimal(value.toString())`.
  - `Double.class`, `Float.class` → `Double.parseDouble`/`Float.parseFloat`.
  - `LocalDate.class` → `LocalDate.parse(value.toString())` (ISO-8601 `YYYY-MM-DD`). Error message: `"expected ISO-8601 date YYYY-MM-DD for " + property`.
  - `LocalDateTime.class` → `LocalDateTime.parse(value.toString())` (ISO-8601 `YYYY-MM-DDTHH:MM:SS`).
  - `OffsetDateTime.class` / `Instant.class` → `OffsetDateTime.parse` / `Instant.parse`.
  - Anything else → `ToolUserError("unsupported_type", "no literal coercion for type " + javaClass.getName())`.

**Special rule for `IN_LIST` / `NOT_IN_LIST`:** value must be a `List`; coerce each element separately; return a `List<Object>` of the coerced elements. Signature: `coerceList(Object raw, MetaProperty mp)`.

**Special rule for `IS_SET`:** value must be a Boolean (true or false); no coercion against the attribute type.

**Switch on sealed `FilterNode` (exhaustive — the compiler enforces this for sealed types):**
```java
public Condition map(FilterNode node, MetaClass mc) {
    return mapInternal(node, mc, /*negated*/ false);
}

private Condition mapInternal(FilterNode node, MetaClass mc, boolean negated) {
    return switch (node) {
        case AndNode a  -> mapLogical(a.and(), mc, negated, /*isAnd*/ true);
        case OrNode  o  -> mapLogical(o.or(),  mc, negated, /*isAnd*/ false);
        case NotNode n  -> mapInternal(n.not(), mc, !negated);      // DeMorgan via flag-flip
        case LeafNode l -> mapLeaf(l, mc, negated);
    };
}

private Condition mapLogical(List<FilterNode> children, MetaClass mc, boolean negated, boolean isAnd) {
    // DeMorgan: NOT(AND(...)) → OR(NOT(child)...), NOT(OR(...)) → AND(NOT(child)...)
    boolean asAnd = isAnd ^ negated;   // XOR with negation flag
    Condition[] mapped = children.stream()
        .map(c -> mapInternal(c, mc, negated))
        .toArray(Condition[]::new);
    return asAnd ? LogicalCondition.and(mapped) : LogicalCondition.or(mapped);
}

private Condition mapLeaf(LeafNode l, MetaClass mc, boolean negated) {
    validatePath(l.property(), mc, 0);                  // D-08: depth cap + per-hop AccessManager
    MetaProperty mp = resolvePropertyPath(mc, l.property());
    String op = resolveOperation(l.operation(), negated);   // negate via op-flip when possible
    Object coerced = coerceValueForOp(op, l.value(), mp);
    return PropertyCondition.createWithValue(l.property(), op, coerced);
}
```

**`resolveOperation(String dslOp, boolean negated)` — case-insensitive D-05 switch + DeMorgan leaf negation:**
```
match dslOp.toUpperCase(Locale.ROOT):
  "EQUAL"            → EQUAL            (negated: NOT_EQUAL)
  "NOT_EQUAL"        → NOT_EQUAL        (negated: EQUAL)
  "GREATER"          → GREATER          (negated: LESS_OR_EQUAL)
  "GREATER_OR_EQUAL" → GREATER_OR_EQUAL (negated: LESS)
  "LESS"             → LESS             (negated: GREATER_OR_EQUAL)
  "LESS_OR_EQUAL"    → LESS_OR_EQUAL    (negated: GREATER)
  "CONTAINS"         → CONTAINS         (negated: DOES_NOT_CONTAIN)
  "DOES_NOT_CONTAIN" → DOES_NOT_CONTAIN (negated: CONTAINS)
  "STARTS_WITH"      → STARTS_WITH      (negated: NOT applicable — throw ToolUserError("not_negatable", ...))
  "ENDS_WITH"        → ENDS_WITH        (negated: NOT applicable — throw)
  "IN_LIST"          → IN_LIST          (negated: NOT_IN_LIST)
  "NOT_IN_LIST"      → NOT_IN_LIST      (negated: IN_LIST)
  "IS_SET"           → IS_SET           (negated: flip the Boolean value, not the op)
  default → throw ToolUserError("unknown_operation", "operator "+dslOp+" not supported",
                                List.of(/* full list of 13 op names */))
```

For STARTS_WITH/ENDS_WITH under NOT: explicitly fail with `ToolUserError("not_negatable", "NOT over STARTS_WITH/ENDS_WITH is not supported in v1; rewrite filter")`. (v1 limitation — DeMorgan cannot express it without regex.)

For IS_SET under negation: dispatch coercion to `coerceBoolean(value, property)` and flip the Boolean before passing as the PropertyCondition value.
