# Quick Task 260420-se6 — Fix JetBrains File Problems (Project-wide)

## Goal
Run IntelliJ inspections (via JetBrains MCP `get_file_problems`) on every Java file modified on branch `gsd/phase-05-rag-layer` vs `master`. Triage each finding into FIX / SKIP (with reason). Apply FIX changes. Verify via `./gradlew build` that nothing regresses.

## Triage rules
- **FIX:**
  - Obvious micro-cleanups that do not change behavior: `TypeReference<List<X>>() {}` → `<>` diamond, unused imports, malformed javadocs, missing `@Override`, missing `@NonNull` on Spring/Jmix `@NonNullApi` overrides.
  - Real bugs: NPE risks, resource leaks, wrong generics, unreachable code that hides intent.
- **SKIP:**
  - "Always true/false" warnings on defensive null checks for 3rd-party APIs whose contract may evolve (Spring AI `Document.getMetadata()` etc.).
  - Warnings explicitly addressed in code comments / javadoc (documented placeholders, reserved-for-future APIs).
  - Style-only noise that conflicts with project conventions.

## Tasks
1. Scan all modified Java files (~115) via `get_file_problems`.
2. Triage output into fix list + skip list with reasons.
3. Apply fixes (Edit).
4. Run `./gradlew compileJava compileTestJava` to confirm no new compile errors.
5. Write SUMMARY.md.

## must_haves
- Every warning from every modified Java file has a triage decision (fix or documented skip).
- Build still green after fixes.
