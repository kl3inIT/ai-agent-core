<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fragment lifecycle -> VaadinSession state | Multiple mounted fragments in one session can receive state changes. |
| Stream lifecycle -> session state | Conversation id state must not become an alternate active-run/cancellation authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Mitigation Plan |
|-----------|----------|-----------|----------|-----------------|
| T-12-03-01 | Tampering | AiChatSessionState listeners | MEDIUM | Listener registry returns unregister handles and ignores unchanged ids to prevent recursive update storms. |
| T-12-03-02 | Denial of Service | UI.access listener dispatch | MEDIUM | Drop updates for detached UIs and unregister on fragment detach. |
| T-12-03-03 | Elevation of Privilege | activeRunId ownership | HIGH | Do not store activeRunId/session-run authority in AiChatSessionState; CancellationRegistry remains the only cancellation source. |
</threat_model>
