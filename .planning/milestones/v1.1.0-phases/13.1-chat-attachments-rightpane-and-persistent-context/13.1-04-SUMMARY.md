# Phase 13.1 Plan 04: CRM-Style Right-Pane Attachments UI Summary

Wave-3 UI port for Phase 13.1 — replaces the Phase 13 inline pill-strip + attachRow inline-upload layout with a verbatim CRM-style horizontal split: chat panel on the left (68%), Attachments panel on the right (32%). The right-pane vbox keeps id="attachmentsPanel" so the Phase 12 ChatSurfaceMounter slot contract is preserved (REQ-7 zero-diff). New `ai-task-file-card-fragment.xml` + `AiTaskFileCardFragmentRenderer.java` deliver the per-row card with DOWNLOAD + TRASH actions; the CSS appendix ports the verbatim CRM stylesheet with a single mechanical selector rename. 13 new `chatView.attachments.*` keys land in both locale bundles. Java fragment controller wiring (data-loader refresh + upload-success handling + budgetExceeded toast) is owned by Plan 13.1-05 — this plan delivers the stable XML/CSS/i18n surface against which Plan 05 builds.

## AiTaskFileCardFragmentRenderer.java

- **209 lines.**
- **Class header:** `@FragmentDescriptor("ai-task-file-card-fragment.xml")` + `@RendererItemContainer("taskFileDc")` + `extends FragmentRenderer<JmixCard, AiTaskFile>`.
- **Public methods:**
  - `onReady(ReadyEvent)` — sets aria labels on open + delete buttons, calls `applyState`.
  - `onItemChange(InstanceContainer.ItemChangeEvent<AiTaskFile>)` — `@Subscribe(id="taskFileDc", target=Target.DATA_CONTAINER)`, re-applies state on row swap.
