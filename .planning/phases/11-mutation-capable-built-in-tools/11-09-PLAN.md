<objective>
Wire `BuiltInLinkTools` (always-on) and `BuiltInMutationTools` (conditional) into `AgentToolCallbacks.forCurrentUser`, and append the `MUTATION_PROMPT_RULES` block to the system prompt when `ai-agent.tools.mutation.enabled=true`.

Purpose: Without this plan, the @Tool methods on `BuiltInLinkTools` / `BuiltInMutationTools` are NOT discovered by the chat callback chain (RESEARCH Q5 — `MethodToolCallbackProvider` is bean-driven, not classpath-scanning). This plan is the integration seam.

Output: `AgentToolCallbacks` accepts new constructor dependencies and includes the new beans' tools in `forCurrentUser`. `AgentSystemPromptRules` exports a `MUTATION_PROMPT_RULES` constant; a NEW sibling top-level class `AgentSystemPromptRulesComposer` (in the same package) holds the conditional composition logic; the existing prompt-composition call site consumes `composer.effectiveRules()`.

Honors: D-09 (TEST-13 callback-count assertion at `forCurrentUser` level), D-07 (no `delete_record` ever), MUT-10 (system-prompt rules wording from CONTEXT.md "Claude's Discretion" verbatim).

Review feedback addressed:
- HIGH audit duplication: mutation callbacks bypass ToolCallbackAuditDecorator because `BuiltInMutationTools` writes exactly one in-method audit row itself.
- HIGH pre-method audit gap: mutation callbacks use `MutationToolCallbackBoundaryDecorator` to audit callback-level binding/invocation failures that happen before the tool method body enters its own try/catch.
- HIGH prompt-rule wiring: `SystemPromptComposer` and `DefaultChatServiceImpl` are explicit files in this plan for both blocking and streaming paths.
- HIGH tool-name leakage scanner: `ToolNamePatternProvider` includes link and mutation built-ins.
- MEDIUM streaming regression: mutation callbacks bypass generic audit wrapping but still emit streaming tool-call/tool-result events through the mutation boundary wrapper.
</objective>

```java
import com.vn.agent.tools.mutation.AiAgentMutationProperties;
import org.springframework.stereotype.Component;

/**
 * Sibling top-level composer that selects between
 * {@link AgentSystemPromptRules#PROMPT_RULES} (read-only baseline) and
 * {@code PROMPT_RULES + MUTATION_PROMPT_RULES} (when
 * {@code ai-agent.tools.mutation.enabled=true}).
 *
 * <p>Wave-4 prompt composer call sites (e.g. DefaultChatServiceImpl —
 * blocking AND streaming per Phase 9 P05) inject this and call
 * {@link #effectiveRules()} where they currently read the bare
 * {@code PROMPT_RULES} constant.
 *
 * <p>Sibling top-level (NOT nested) because the codebase has no precedent for
 * nested {@code @Component} static classes; sibling top-level matches existing
 * structure and avoids loader-ordering quirks.
 */
@Component
public class AgentSystemPromptRulesComposer {

    private final AiAgentMutationProperties mutationProperties;

    public AgentSystemPromptRulesComposer(AiAgentMutationProperties mutationProperties) {
        this.mutationProperties = mutationProperties;
    }

    public String effectiveRules() {
        if (mutationProperties.resolvedEnabled()) {
            return AgentSystemPromptRules.PROMPT_RULES + AgentSystemPromptRules.MUTATION_PROMPT_RULES;
        }
        return AgentSystemPromptRules.PROMPT_RULES;
    }
}
```
