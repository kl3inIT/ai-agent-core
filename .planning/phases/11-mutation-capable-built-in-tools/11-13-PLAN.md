  <action>
1. Create `com.vn.agent.audit.MutationArgumentSanitizer` as a Spring `@Component`.
2. Constructor-inject `com.fasterxml.jackson.databind.ObjectMapper` and `AiAgentAuditProperties`.
3. Add method `public String sanitize(String toolName, String toolInput)`.
4. Treat exactly these mutation tool names as known mutation input shapes: `create_record`, `update_record`, `add_related_record`, `remove_related_record`.
5. For known mutation tool names and valid JSON object input:
   - Parse with `ObjectMapper.readTree(toolInput)`.
   - Recursively copy the JSON tree.
   - Whenever an object field name is in `auditProperties.resolvedSensitiveFields()` and `auditProperties.resolvedHashSensitiveFields()` is true, replace scalar values with `AuditFieldHasher.sha256Hex(value.asText())`.
   - Preserve JSON numbers, booleans, nulls, arrays, non-sensitive strings, `entityName`, `id`, `relationship`, `relatedId`, and `idempotencyKey`.
   - Write the sanitized JSON back to a compact string with `ObjectMapper.writeValueAsString(...)`.
6. For known mutation tool names and non-JSON, invalid JSON, or non-object JSON input, return the exact placeholder JSON string `{"sanitized":true,"reason":"unparseable_mutation_arguments"}`. Do not include raw input length, raw snippets, parse exception text, or user-supplied values.
7. For unknown tool names, return the exact placeholder JSON string `{"sanitized":true,"reason":"unknown_mutation_tool"}`. The decorator is mutation-only, so this branch is defensive.
8. In `MutationToolCallbackBoundaryDecorator`, add a constructor parameter and field named `mutationArgumentSanitizer`.
9. In `callInternal`, compute `String safeInput = cap(mutationArgumentSanitizer.sanitize(toolName, toolInput), ARGUMENTS_JSON_MAX_CHARS);`.
10. Use `safeInput` in `new StreamingEvent.ToolCall(toolCallId, toolName, safeInput)` and in the fallback `auditWriter.writeToolCall(...)` argumentsJson parameter.
11. Continue passing the original raw `toolInput` to `delegate.call(...)`; do not sanitize the value used by Spring AI binding or the mutation tool body.
12. Update `AgentToolCallbacks` constructor injection to receive `MutationArgumentSanitizer` and pass it into every `new MutationToolCallbackBoundaryDecorator(...)` call.
13. Do not change `ToolCallbackAuditDecorator`; read/link/contributor callbacks keep their existing generic behavior.
  </action>
