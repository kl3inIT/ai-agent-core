<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller (User-A) → ChatService.ask | userId from authenticated session is the sole authority for conversation ownership. |
| ChatService → ConversationGateway | conversationId may be attacker-controlled (probe for other users' IDs) — ownership check is mandatory and opaque. |
| ChatClient → tool callbacks | Tool inputs come from the LLM (potentially adversarial) — wrapping with ToolCallbackAuditDecorator ensures every call is logged. |
| ProjectingChatMemoryRepository → AiMessage | Projection joins outer tx so a Jmix policy violation rolls back BOTH the AiMessage and the SPRING_AI_CHAT_MEMORY row. |
