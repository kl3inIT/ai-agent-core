<objective>
Extend `BaselineContextProvider` to emit two new deterministic prompt keys — `agent.entities` and `agent.permissions` — sourced from `CurrentUserSchemaAccess.getReadableSchema()` and `AccessManager`, with **locale-sensitive labels resolved per request and never embedded in any cache key** (P-8 mitigation; explicit PROMPT-02 wording).

Per locked CONTEXT.md decisions:
- D-01: `agent.entities` renders as `name (label)` per line, alphabetical by `MetaClass.getName()`, single multi-line value under one prompt key. Empty schema → key omitted entirely.
- D-02: `agent.permissions` is a compact JSON object keyed by entity. Each value is a `LinkedHashMap` with key order `r, u, c, d, modifiable`. Booleans render as `1`/`0` ints. `modifiable[]` is alphabetically sorted. Entries where ALL CRUD bits are 0 are omitted. Locale labels are NOT in `agent.permissions`.
- D-03: truncation default **100 entities**; configurable via `jmix.ai-agent.prompt.entity-inventory.limit`. When schema size > limit, render top-100 alpha + trailing `... (truncated, call list_entities for full list)`.
- TOOL-12: only entities the user is allowed to read appear; denied entities NEVER leak (consistent with v1 "denied = does not exist" opacity).

Phase 10 will substitute the source from `CurrentUserSchemaAccess` to `LlmExposurePolicy` in this same site without churning call sites — Plan 09-03 deliberately routes through `CurrentUserSchemaAccess` so Plan 10's substitution is a one-class change.

```java
/**
 * D-01: alphabetical-by-name list of {@code "name (label)"} lines, joined with {@code \n}.
 * D-03 truncation: at limit, drop tail and append a trailing hint line.
 */
private String renderEntitiesBlock(Map<MetaClass, Set<String>> readableSchema) {
    int limit = promptProperties.resolvedEntityInventoryLimit();
    List<MetaClass> sorted = new ArrayList<>(readableSchema.keySet());
    sorted.sort(Comparator.comparing(MetaClass::getName));
    boolean truncated = sorted.size() > limit;
    if (truncated) {
        sorted = sorted.subList(0, limit);
    }
    StringBuilder sb = new StringBuilder();
    boolean first = true;
    for (MetaClass mc : sorted) {
        if (!first) sb.append('\n');
        sb.append(mc.getName()).append(" (").append(messageTools.getEntityCaption(mc)).append(')');
        first = false;
    }
    if (truncated) {
        sb.append('\n').append("... (truncated, call list_entities for full list)");
    }
    return sb.toString();
}

/**
 * D-02: compact JSON keyed by entity name, alpha-sorted. Each value is a {@link LinkedHashMap}
 * with key order {@code r, u, c, d, modifiable} so Jackson emits keys in that order. CRUD bits
 * are ints (1/0). Entries where ALL CRUD bits are 0 are omitted (D-02). {@code modifiable[]}
 * lists per-attribute names that pass {@code EntityAttributeContext.canModify()}, alpha-sorted.
 *
 * &lt;p&gt;&lt;b&gt;Locale-free:&lt;/b&gt; this string contains zero locale-resolved labels — only entity
 * metaclass names and attribute names. Cache-key safe (P-8).
 *
 * @return JSON string, or {@code null} if no entity has any CRUD bit set (degenerate edge case)
 */
private String renderPermissionsJson(Map<MetaClass, Set<String>> readableSchema) {
    Map<String, Object> permissions = new TreeMap<>();
    for (MetaClass mc : readableSchema.keySet()) {
        CrudEntityContext crud = new CrudEntityContext(mc);
        accessManager.applyRegisteredConstraints(crud);
        int r = crud.isReadPermitted() ? 1 : 0;
        int u = crud.isUpdatePermitted() ? 1 : 0;
        int c = crud.isCreatePermitted() ? 1 : 0;
        int d = crud.isDeletePermitted() ? 1 : 0;
        if (r == 0 && u == 0 && c == 0 && d == 0) {
            continue; // D-02: skip entries with no CRUD bits set
        }
        Map<String, Object> entry = new LinkedHashMap<>();
        entry.put("r", r);
        entry.put("u", u);
        entry.put("c", c);
        entry.put("d", d);
        entry.put("modifiable", modifiableAttributesOf(mc, readableSchema.get(mc)));
        permissions.put(mc.getName(), entry);
    }
    if (permissions.isEmpty()) {
        return null;
    }
    try {
        return objectMapper.writeValueAsString(permissions);
    } catch (JsonProcessingException e) {
        throw new IllegalStateException("Failed to serialize agent.permissions", e);
    }
}

/**
 * D-02: per-attribute {@code modifiable} list — names where
 * {@link EntityAttributeContext#canModify()} returns {@code true}, alpha-sorted. Bounded to
 * the {@code readableAttributeNames} set (the user has READ on these; we test MODIFY on the
 * same subset).
 */
private List<String> modifiableAttributesOf(MetaClass metaClass, Set<String> readableAttributeNames) {
    List<String> modifiable = new ArrayList<>();
    for (String attributeName : new TreeSet<>(readableAttributeNames)) {
        EntityAttributeContext ctx = new EntityAttributeContext(metaClass, attributeName);
        accessManager.applyRegisteredConstraints(ctx);
        if (ctx.canModify()) {
            modifiable.add(attributeName);
        }
    }
    return modifiable; // already alpha-sorted via TreeSet iteration
}
```
