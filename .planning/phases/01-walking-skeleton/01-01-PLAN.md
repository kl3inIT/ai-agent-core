## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer → Gradle build | Build scripts can pull arbitrary deps from Maven Central + global.repo.jmix.io + repo.spring.io. Supply-chain risk. |
| jmix-app runtime → OpenRouter (HTTPS) | User prompts + API key cross this boundary. Not exercised in Phase 1, but the wiring lands here. |
| Env var → application.yaml | `OPENROUTER_API_KEY` must never be logged or committed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering (supply chain) | `ai-agent/build.gradle` BOM import | mitigate | `mavenCentral()` listed FIRST in repos (Gradle first-hit wins); BOM pin (`spring-ai-bom:2.0.0-M4`) forbids drift on transitive Spring AI versions. |
| T-01-02 | Information disclosure | `jmix-app/application.yaml` | mitigate | API key via `${OPENROUTER_API_KEY:none}` env-var indirection; literal fallback "none" is intentionally invalid (fails closed with 401). No `.env` file created by this plan. |
| T-01-03 | Information disclosure | Spring Boot config logging | accept | Default Spring Boot sensitive-property masking covers `spring.ai.openai.api-key`. No logging-config changes needed in Phase 1. |
| T-01-04 | DoS / cost | Default `./gradlew test` run | mitigate | `excludeTags 'live'` in `tasks.named('test')` — live suite never fires in the default task. Plan 03 adds the belt-and-suspenders `@EnabledIfEnvironmentVariable` guard. |
| T-01-05 | Spoofing (HTTPS) | OpenRouter endpoint | mitigate | `base-url` defaults to HTTPS `https://openrouter.ai/api/v1` — no plaintext fallback allowed; env override must also be HTTPS (doc in Plan 04 version matrix). |
</threat_model>
