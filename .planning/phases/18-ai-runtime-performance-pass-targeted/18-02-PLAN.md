ONLY in `LlmExposurePolicy` + `RunContext`, never in `BuiltInDataTools`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| per-turn ThreadLocal → next turn / next user | A memoized schema/verdict that outlives `RunContext.clear()` would be reused under a different user's turn on a pooled Vaadin/streaming thread — authorization bypass. |
| LLM schema/verdict cache → row-data path | The per-turn cache must never become the access decision for actual row reads; `AccessManager`/constrained `DataManager` stay authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-04 | Elevation of Privilege / Information Disclosure | per-turn schema/verdict memo reused across turns or users | mitigate | ThreadLocal scoped to one turn + `PER_TURN_CACHE.remove()` in `clear()` (D-01); `LlmExposurePerTurnMemoTest` proves `assertThat(perTurnCache()).isEmpty()` after `clear()` and recompute on the next turn. |
| T-18-05 | Information Disclosure | Streaming foreign-thread ThreadLocal absence "fixed" by cross-thread propagation of the sensitive map | mitigate | D-02 safe-miss: null on a foreign thread = fresh empty map (recompute), never stale; explicitly forbid `ConcurrentHashMap<runId>` and reactor-Context propagation. |
| T-18-06 | Elevation of Privilege | Cache leaks into the constrained-`DataManager` row-data path (`BuiltInDataTools`) | mitigate | D-09 boundary: `PerTurnCacheBoundaryInvariantTest` source-scans the cache symbol out of `BuiltInDataTools`; the cache memoizes only the LLM-facing schema/verdict surface. |
| T-18-07 | Elevation of Privilege | Over-permissive verdict memoized mid-turn after a permission change | accept | Within a turn the user/role/registered-constraints are immutable; the only verdict-changing event is the across-turn `LlmExposureChangedEvent` (app-wide denylist evicts on it; per-turn map wiped each turn). D-08. |
| T-18-SC | Tampering | npm/pip/cargo installs | mitigate | N/A — zero packages installed. |
</threat_model>
