    Implement `public static Map<Object, Object> perTurnCache()` as:
    - If `CURRENT.get() == null` (NO active turn — foreign streaming worker thread, or after `clear()`):

      `PER_TURN_CACHE.set(...)`. This guarantees NOTHING is left on a pooled thread outside a turn and that
      the post-`clear()` map is observably empty WITHOUT a fresh allocation masking the wipe.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| per-turn ThreadLocal → next turn / next user | A memoized schema/verdict that outlives `RunContext.clear()` would be reused under a different user's turn on a pooled Vaadin/streaming thread — authorization bypass. |
| LLM schema/verdict cache → row-data path | The per-turn cache must never become the access decision for actual row reads; `AccessManager`/constrained `DataManager` stay authoritative. |

| T-18-04 | Elevation of Privilege / Information Disclosure | per-turn schema/verdict memo reused across turns or users | mitigate | ThreadLocal scoped to one turn + `PER_TURN_CACHE.remove()` in `clear()` (D-01); `LlmExposurePerTurnMemoTest` proves `assertThat(perTurnCache()).isEmpty()` after `clear()` and recompute on the next turn. |
| T-18-05 | Information Disclosure | Streaming foreign-thread ThreadLocal absence "fixed" by cross-thread propagation of the sensitive map, OR a map left on a pooled thread outside a turn | mitigate | D-02 safe-miss is ACTIVE-TURN-GATED (review HIGH #3): no active turn (`RunContext.get() == null`) ⇒ recompute-WITHOUT-store (never allocate/store a map on a pooled worker thread, never stale reuse); explicitly forbid `ConcurrentHashMap<runId>` and reactor-Context propagation; the non-initializing `perTurnCacheSnapshotForTest` proves the slot is genuinely null after `clear()`. |
