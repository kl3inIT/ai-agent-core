## AuditWriter Methods & Transactional Flags

| Method           | Propagation   | Fan-out kind | Fetch plan                                                        |
| ---------------- | ------------- | ------------ | ----------------------------------------------------------------- |
| writeChatStart   | REQUIRES_NEW  | (none — D-05)| INSERT only                                                       |
| writeChatFinish  | REQUIRES_NEW  | CHAT         | `kind, outcome, latencyMs, finishedAt, errorClass, startedAt` (no `children`) |
| writeToolCall    | REQUIRES_NEW  | TOOL         | parent lookup with `id` only                                      |
| writeRetrieval   | REQUIRES_NEW  | RETRIEVAL    | parent lookup with `id` only                                      |

All four writers annotated `@Transactional(propagation = Propagation.REQUIRES_NEW)`; `registerAfterCommit(auditId, kind)` helper dispatches via `TransactionSynchronizationManager.registerSynchronization` on the REQUIRES_NEW tx.
