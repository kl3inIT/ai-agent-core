# Phase 07.2 Plan 01: Audit Schema Tree-Lite Foundation Summary

Foundation layer for tree-lite audit schema: new self-referential `AiAuditEvent` entity and `AI_AGENT_AUDIT_EVENT` table replace flat `AiToolCallAudit`; `AuditListener` SPI rewritten with kind-agnostic `onEventAudited(UUID, String)`; `AuditKind` constants and bilingual i18n updates complete.

## DDL Changesets (090-ai-audit-event.xml)

- `id="1"` — preCondition-gated `<dropTable AI_AGENT_TOOL_CALL_AUDIT cascadeConstraints="true"/>` (MARK_RAN on fresh DB)
- `id="2"` — `<createTable AI_AGENT_AUDIT_EVENT>` with 23 columns (tree + retrieval + carry-over)
- `id="3"` — two `<addForeignKeyConstraint>`: `FK_AI_AGENT_AUDIT_EVENT__ON_PARENT` (self) + `FK_AI_AGENT_AUDIT_EVENT__ON_CONVERSATION`
- `id="4"` — four `<createIndex>`: parent, conversation, started_at, run_id

Types use `${uuid.type}` and `${offsetDateTime.type}` (fixing the `datetime` literal used by legacy `030-`).

## SPI Changes

- `AuditKind` (new) — public final class in `com.vn.agent.spi` with `String` constants `CHAT`/`TOOL`/`RETRIEVAL` (D-03, open-ended kinds).
- `AuditListener` (breaking rewrite) — old `onToolCallAudited(UUID)` removed; replaced by `onEventAudited(UUID auditId, String kind)`. Javadoc documents kind-tolerance contract.
