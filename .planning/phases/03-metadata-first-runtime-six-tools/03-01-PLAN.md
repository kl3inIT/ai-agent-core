**Responsibilities:**
1. Constructor-inject `Metadata metadata` (CLAUDE.md: constructor injection only).
2. On `ApplicationReadyEvent` (NOT `@PostConstruct` — Pitfall 1), walk `metadata.getSession().getClasses()`.
3. Skip classes annotated `@io.jmix.core.entity.annotation.SystemLevel`.
4. For each surviving `MetaClass`, build `AiEntityInfo`:
   - `metaClass`: the raw reference
   - `entityName`: `mc.getName()` (D-11, verbatim — keep the `jmixapp_` prefix)
   - `localizedLabel`: `null` (resolved per-request by EffectiveSchemaComputer — D-04)
   - `attributes`: one `AiAttributeInfo` per `MetaProperty` via `buildAttributeInfo(mp)`
5. In parallel, build the `UserEditableStringIndex`:
   - For each `MetaClass`, collect property names where ALL hold:
     - `mp.getRange().isDatatype()` AND the datatype's Java class is `String.class`
     - `mp.getStore().getName()` is a persistent store (i.e. not computed/transient) — use `mp.getRange().isClass() == false && mp.getRange().isEnum() == false && mp.isReadOnly() == false` as a conservative read (string-typed + not association/enum + not read-only). Actual test: `mp.isPersistent()` via `((io.jmix.core.metamodel.model.impl.MetaPropertyImpl) mp)` — but that's an impl API. Safe portable approach: `mp.getAnnotatedElement() instanceof java.lang.reflect.Field` AND that field has `@jakarta.persistence.Column` OR no `@Transient`.
     - Java field not annotated `@io.jmix.core.entity.annotation.SystemLevel`.
     - Attribute name NOT in framework-managed set: `{"id", "version", "createdBy", "createdDate", "lastModifiedBy", "lastModifiedDate", "deletedBy", "deletedDate"}`.
6. Store both (raw `AiSchema` + `UserEditableStringIndex`) in `volatile` fields; expose via `getRawSchema()` + `getUserEditableStringIndex()`. Throw `IllegalStateException("scan() not yet run")` if accessed pre-event.

**`buildAttributeInfo(MetaProperty mp)` rules (D-02):**
- `name = mp.getName()`
- `typeLabel`: if `mp.getRange().isEnum()` → `"enum:" + mp.getRange().asEnumeration().getJavaClass().getSimpleName()`; else if `mp.getRange().isClass()` → `"ref:" + mp.getRange().asClass().getName()`; else if `mp.getRange().isDatatype()` → `mp.getRange().asDatatype().getJavaClass().getSimpleName()`.
- `nullable = !mp.isMandatory()`
- `enumValues`: if enum, list of `Enum.name()` for every constant of the enum Java class (use `javaClass.getEnumConstants()`); else `null`.
- `relationshipTarget`: if association, `mp.getRange().asClass().getName()` (Jmix entity name); else `null`.
- `validationConstraints`: scan `mp.getAnnotatedElement().getAnnotations()` — capture descriptors for `@NotNull`, `@Size` (with `min`/`max`), `@Pattern` (with `regexp`). Ignore others. Format: `"NotNull"`, `"Size(min=0,max=32)"`, `"Pattern(regexp=^[A-Z]+$)"`.
- `localizedLabel`: `null` (D-04 per-request).

```java
package com.vn.agent.metadata;

import io.jmix.core.Metadata;
import io.jmix.core.entity.annotation.SystemLevel;
import io.jmix.core.metamodel.model.MetaClass;
import io.jmix.core.metamodel.model.MetaProperty;
import jakarta.annotation.Nullable;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Pattern;
import jakarta.validation.constraints.Size;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;

import java.lang.reflect.AnnotatedElement;
import java.util.*;

@Component
public class MetamodelScanner {

    private static final Set<String> FRAMEWORK_MANAGED = Set.of(
        "id", "version", "createdBy", "createdDate",
        "lastModifiedBy", "lastModifiedDate", "deletedBy", "deletedDate"
    );

    private final Metadata metadata;
    private volatile AiSchema rawSchema;
    private volatile UserEditableStringIndex userEditableStringIndex;

    public MetamodelScanner(Metadata metadata) { this.metadata = metadata; }

    @EventListener(ApplicationReadyEvent.class)
    public void scan() {
        Map<String, AiEntityInfo> entities = new LinkedHashMap<>();
        Map<String, Set<String>> uei = new LinkedHashMap<>();
        for (MetaClass mc : metadata.getSession().getClasses()) {
            if (mc.getJavaClass().isAnnotationPresent(SystemLevel.class)) continue;
            List<AiAttributeInfo> attrs = new ArrayList<>();
            Set<String> userEditable = new LinkedHashSet<>();
            for (MetaProperty mp : mc.getProperties()) {
                attrs.add(buildAttributeInfo(mp));
                if (isUserEditableString(mp)) userEditable.add(mp.getName());
            }
            entities.put(mc.getName(),
                new AiEntityInfo(mc, mc.getName(), null, attrs));
            uei.put(mc.getName(), Set.copyOf(userEditable));
        }
        this.rawSchema = new AiSchema(entities);
        this.userEditableStringIndex = new UserEditableStringIndex(uei);
    }

    public AiSchema getRawSchema() {
        if (rawSchema == null) throw new IllegalStateException("scan() not yet run");
        return rawSchema;
    }
    public UserEditableStringIndex getUserEditableStringIndex() {
        if (userEditableStringIndex == null) throw new IllegalStateException("scan() not yet run");
        return userEditableStringIndex;
    }

    private AiAttributeInfo buildAttributeInfo(MetaProperty mp) { /* per D-02 rules above */ }
    private boolean isUserEditableString(MetaProperty mp) { /* per D-13 rules above */ }
}
```

```java
import io.jmix.core.MessageTools;
import io.jmix.core.accesscontext.CrudEntityContext;
import io.jmix.core.accesscontext.EntityAttributeContext;

@Component
public class EffectiveSchemaComputer {
    private final AccessManager accessManager;
    private final MetamodelScanner scanner;
    private final MessageTools messageTools;

    public EffectiveSchemaComputer(AccessManager accessManager,
                                   MetamodelScanner scanner,
                                   MessageTools messageTools) {
        this.accessManager = accessManager;
        this.scanner = scanner;
        this.messageTools = messageTools;
    }

    public boolean canReadAttribute(MetaClass mc, String attrPath) {

    public boolean canReadEntity(MetaClass mc) {
        CrudEntityContext ec = new CrudEntityContext(mc);
        accessManager.applyRegisteredConstraints(ec);

}
```
