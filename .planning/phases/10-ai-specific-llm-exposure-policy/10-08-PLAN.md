6. Add `@Subscribe("documentsDataGrid.editPermissions")` handler:
```java
@Subscribe("documentsDataGrid.editPermissions")
public void onEditPermissions(ActionPerformedEvent event) {
    AiKnowledgeDocument doc = documentsDataGrid.getSingleSelectedItem();
    if (doc == null) return;
    // Open edit dialog / inline form for allowedRoles + sourceEntityName
    // Then on confirm: show reingest confirmation dialog
    dialogs.createOptionDialog()
        .withHeader(messages.getMessage(getClass(), "knowledgeBase.confirm.editPermissions.reingest.title"))
        .withText(messages.getMessage(getClass(), "knowledgeBase.confirm.editPermissions.reingest.body"))
        .withActions(
            new DialogAction(DialogAction.Type.OK).withHandler(e -> {
                // Save + reingest
                try {
                    dataManager.save(doc);
                    knowledgeDocumentService.reingest(doc.getId());
                    documentsDl.load();
                } catch (Exception ex) {
                    notifications.show(messages.getMessage(getClass(),
                        "knowledgeBase.error.editPermissionsReingest"));
                }
            }),
            new DialogAction(DialogAction.Type.CANCEL))
        .open();
}
```
Note: The pattern for accessing allowedRoles + sourceEntityName editing may need a small inline dialog (DialogWindow) or may reuse an existing form; executor should choose the simplest approach consistent with the existing view pattern. @Supply(to = "documentsDataGrid.sourceEntity", subject = "renderer")
private ComponentRenderer<Span, AiKnowledgeDocument> sourceEntityRenderer() {
    return new ComponentRenderer<>(doc -> {
        Span span = new Span();
        if (doc.getSourceEntityName() != null) {
            MetaClass mc = metadata.findClass(doc.getSourceEntityName());
            span.setText(mc != null
                ? messageTools.getEntityCaption(mc) + " (" + doc.getSourceEntityName() + ")"
                : doc.getSourceEntityName());
        } else {
            span.setText("—");
        }
        return span;
    });
}
