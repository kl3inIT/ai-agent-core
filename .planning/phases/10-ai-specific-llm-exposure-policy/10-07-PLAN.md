Create `AiExposureRuleDetailView.java` in `com.vn.agent.view.exposure`:
- `@Route(value = "ai-agent/exposure-rules/:id", layout = DefaultMainViewParent.class)`
- `@ViewController(id = "AiAgent_AiExposureRule.detail")`
- `@ViewDescriptor(path = "ai-exposure-rule-detail-view.xml")`
- `@EditedEntityContainer("exposureRuleDc")`
- Extends `StandardDetailView<AiExposureRule>`
- `@Autowired private MetaclassComboBoxHelper metaclassComboBoxHelper;`
- `@Autowired private MessageTools messageTools;`
- `@ViewComponent private TypedComboBox<MetaClass> entityNameComboBox;` (or `ComboBox<MetaClass>` — use Vaadin `com.vaadin.flow.component.combobox.ComboBox<MetaClass>`)
- `@ViewComponent private InstanceContainer<AiExposureRule> exposureRuleDc;`
- `@Subscribe` `InitEvent` handler:
  - Populate items: `entityNameComboBox.setItems(metaclassComboBoxHelper.buildFilteredList())`
  - Set item label generator: `entityNameComboBox.setItemLabelGenerator(mc -> messageTools.getEntityCaption(mc) + " (" + mc.getName() + ")")`
- `@Subscribe` `BeforeShowEvent` handler (or `ReadyEvent`):
  - If `exposureRuleDc.getItem().getEntityName()` is non-null (editing existing), find matching MetaClass and pre-select: `Metadata metadata` injected, `MetaClass mc = metadata.findClass(rule.getEntityName()); if (mc != null) entityNameComboBox.setValue(mc);`
- `@Subscribe("entityNameComboBox")` `AbstractField.ComponentValueChangeEvent` handler:
  - `MetaClass selected = entityNameComboBox.getValue(); if (selected != null) exposureRuleDc.getItem().setEntityName(selected.getName());`
- Add `@Autowired private Metadata metadata;` for the pre-select lookup
