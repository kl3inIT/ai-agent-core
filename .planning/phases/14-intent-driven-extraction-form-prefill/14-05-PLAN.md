  <action>
    1. Create `DraftLoader.apply(UUID draftId, Object editingEntity)` returning `DraftApplyResult`.
    2. Load `AiExtractionDraft` by id through secured `DataManager`. If missing, throw `DraftNotFoundException`.
    3. Verify `draft.targetEntityName` matches `metadata.getClass(editingEntity).getName()` before applying.
    4. Parse `payloadJson` into `Map<String, Object>` with Jackson.
    5. For each entry:
       - Resolve `MetaProperty`; unknown properties are skipped and counted as denied/skipped.
       - Build `EntityAttributeContext(metaClass, attributeName)`, apply registered constraints, and continue only if `canModify()` is true.
       - Coerce scalar, enum, date/time, number, boolean, and to-one UUID string values using existing mutation binder/converter patterns where possible.
       - Set the value only through a local helper named `setValueIfPermitted(...)`; the helper is the only place in the draft package allowed to call `EntityValues.setValue(...)`.
    6. Collect `appliedFieldCount`, `deniedAttributeCount`, and up to 16 denied attribute names.
    7. Write `AuditWriter.writeToolCall(eventName = "extraction.draft_applied", ...)` with counts and bounded names, not values.
    8. Do not delete the draft in `DraftLoader`; save-time deletion belongs to `OpenFormWithDraftHandler`.
  </action>
