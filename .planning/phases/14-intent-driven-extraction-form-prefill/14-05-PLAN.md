  <action>
    1. Create `DraftLoader.apply(UUID draftId, Object editingEntity)` returning `DraftApplyResult`.
    2. Load `AiExtractionDraft` by id through secured `DataManager`. If missing, throw `DraftNotFoundException`.
    3. Verify `draft.targetEntityName` matches `metadata.getClass(editingEntity).getName()` before applying.
    4. Parse `payloadJson` into `Map<String, Object>` with Jackson.
    5. For each entry:
       - Resolve `MetaProperty`; unknown properties are skipped and counted as denied/skipped.
       - Build `EntityAttributeContext(metaClass, attributeName)`, apply registered constraints, and continue only if `canModify()` is true.
       - Coerce scalar, enum, date/time, number, boolean, and to-one UUID string values using existing mutation binder/converter patterns where possible.
       - Set the value only through a local helper named `setValueIfPermitted(...)`; the helper is the only place in the draft package allowed to call `EntityValues.setValue(...)`.
    6. Collect `appliedFieldCount`, `deniedAttributeCount`, and up to 16 denied attribute names.
    7. Write `AuditWriter.writeToolCall(eventName = "extraction.draft_applied", ...)` with counts and bounded names, not values.
    8. Do not delete the draft in `DraftLoader`; save-time deletion belongs to `OpenFormWithDraftHandler`.
  </action>

    2. Inject `ViewNavigators`, `AccessManager`, `ViewRegistry` or the Jmix API needed to resolve primary detail view id, `Metadata`, `DataManager`, `DraftLoader`, `Messages`, and `Notifications`.
    3. Public method: `open(View<?> originView, UUID draftId, String entityName, String instanceName)` or `open(Component hostComponent, ...)` that immediately resolves `UiComponentUtils.getView(hostComponent)`. The session-scoped handler must receive the current owner on every call and must not cache it.
    4. Load the draft by id first through secured `DataManager`; throw/return expired state if missing.
    5. Resolve `MetaClass` and Java class from `entityName`; verify it matches the draft row.
    6. Resolve the primary detail view id and check `AccessManager` with `UiShowViewContext(detailViewId)` before navigation.
    7. If not permitted, show localized `chatView.intent.permissionDenied` notification and return a denied result; do not navigate.
    8. If permitted, resolve `ViewInfo detailViewInfo = viewRegistry.getDetailViewInfo(metaClass)` and its `controllerClass`. Verify the controller is assignable to `StandardDetailView`; if not, show a localized configuration error and do not navigate.
    9. Navigate with the documented Jmix 2.8 class navigator path:
       `viewNavigators.detailView(originView, entityClass).newEntity().withViewClass(detailViewClass).withAfterNavigationHandler(event -> { ... }).navigate()`.
       `ViewNavigators.newEntity()` is the creation API; `DetailViewClassNavigator.withAfterNavigationHandler(...)` is the post-navigation configuration hook.
    10. In the after-navigation handler, cast `event.getView()` to `StandardDetailView<?>`, obtain `detailView.getEditedEntity()`, and call `draftLoader.apply(draftId, editedEntity)`. Because `StandardDetailView.initNewEntity()` creates the entity through the view `DataContext`, the edited entity is already tracked; if implementation evidence shows a detached entity path, explicitly use `detailView.getViewData().getDataContext().merge(editedEntity)` before applying and assert this in tests.
    11. Register save and close listeners through `ComponentUtil.addListener(detailView, StandardDetailView.AfterSaveEvent.class, ...)` and `ComponentUtil.addListener(detailView, View.AfterCloseEvent.class, ...)` so protected `addAfterSaveListener` / `addAfterCloseListener` methods are not called from outside the view class.
    12. On `StandardDetailView.AfterSaveEvent`, set `confirmed=true` and delete the draft row after successful Save through secured `DataManager`, then remove both listener registrations. On `View.AfterCloseEvent` without save, remove registrations only and leave the draft for TTL cleanup.
    13. Do not add a close/cancel listener that deletes drafts.
  </action>
