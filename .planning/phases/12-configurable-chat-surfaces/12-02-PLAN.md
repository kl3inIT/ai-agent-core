- a default-surface select/radio field initialized from `AiChatSurface.values()`
- save/close actions using Jmix standard actions where possible

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin browser -> AiUiSettings view | Only administrators should alter global chat surface availability. |
| Settings validation -> host UX | Invalid settings could hide all chat entry points or point defaultSurface at a disabled surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Mitigation Plan |
|-----------|----------|-----------|----------|-----------------|
| T-12-02-01 | Elevation of Privilege | AiUiSettingsDetailView | HIGH | Gate with Jmix `@ViewPolicy`, `@MenuPolicy`, and `@EntityPolicy`; add access tests. |
| T-12-02-02 | Denial of Service | AiUiSettings validation | MEDIUM | Reject empty enabledSurfaces and default surface not in enabledSurfaces. |
| T-12-02-03 | Information Disclosure | Locale/UI text | LOW | Use root bundles and avoid internal tool/entity vocabulary in user-facing labels. |
</threat_model>
