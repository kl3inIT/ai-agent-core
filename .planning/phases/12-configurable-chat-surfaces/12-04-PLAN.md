<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vaadin UI init/navigation -> host shell | Add-on injects UI into host AppLayout without host code edits. |
| Settings/security -> rendered chat entry points | Button/menu/route visibility must reflect both admin settings and Jmix permissions. |
| Dialog lifecycle -> conversation state | Closing/hiding UI must not destroy the conversation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Mitigation Plan |
|-----------|----------|-----------|----------|-----------------|
| T-12-04-01 | Elevation of Privilege | Header button | HIGH | Apply Jmix `UiShowViewContext("AiAgent_ChatDialog")`; hide button when not permitted. |
| T-12-04-02 | Spoofing/Tampering | Custom shell fallback | MEDIUM | Do not mount a floating fallback over arbitrary screens; warn and leave FULL_ROUTE as fallback. |
| T-12-04-03 | Denial of Service | Duplicate mounts | MEDIUM | Stable button id/state and tests ensure one navbar button per UI. |
| T-12-04-04 | Information Disclosure | Disabled route | HIGH | Hide menu and block direct route when FULL_ROUTE disabled. |
</threat_model>
