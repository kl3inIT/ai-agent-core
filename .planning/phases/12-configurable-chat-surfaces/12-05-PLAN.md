<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Conversation content -> title prompt | User/assistant text is sent to the configured chat model for a compact persistent label. |
| Async title job -> agentstore | Background job updates persistent conversation title after chat reply path completes. |
| User manual title edit -> conversation row | User can alter title shown in UI and audit context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Mitigation Plan |
|-----------|----------|-----------|----------|-----------------|
| T-12-05-01 | Tampering | Auto-title save | HIGH | Reload before save and skip if title no longer equals default sentinel. |
| T-12-05-05 | Tampering | Auto-title event timing | HIGH | Consume with `@TransactionalEventListener(AFTER_COMMIT)` or prove an equivalent durable post-save boundary so generated titles never race uncommitted assistant messages. |
| T-12-05-02 | Information Disclosure | Title prompt/audit | HIGH | Do not include raw tool JSON; sanitize title; audit compact metadata, not raw prompt context. |
| T-12-05-03 | Denial of Service | Async title calls | MEDIUM | One call per new conversation, max context messages, maxTokens=32, fail-silent on provider errors. |
| T-12-05-04 | Repudiation | Title generation | MEDIUM | Audit SUCCESS and ERROR with model/outcome/latency where available. |
</threat_model>
