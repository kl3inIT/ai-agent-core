<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test JVM → embedded HSQLDB | Test asserts on information_schema — a SQL injection in a literal would be self-inflicted; inputs are constants |
| test → Jmix security | Test intentionally switches identities via SystemAuthenticator; an incorrect switch silently passes/fails row-level assertions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10-01 | Spoofing | `SystemAuthenticator.begin("bob")` silently falls back to anonymous if "bob" unknown | mitigate | Row-level assertion requires BOTH a positive result under alice AND empty under bob; silent anonymous fallback would make the alice-positive assertion fail too. |
| T-02-10-02 | Tampering | `assertTableExists` via `information_schema` is case-sensitive on some DBs | mitigate | Helper uses `upper(table_name) = ?` + uppercase literal; works on HSQLDB, PostgreSQL, and most RDBMs. |
| T-02-10-03 | Information Disclosure | Test accidentally LOGS row contents or embeds PII | accept | Test uses synthetic titles ("test conv", etc.); no real PII. |
| T-02-10-04 | Denial of Service | `@SpringBootTest` cold-starts the full context for every run | accept | One test class only; Gradle caches JVM between methods via JUnit 5's default runner. |
| T-02-10-05 | Repudiation | A false green because Liquibase silently skipped the add-on changelog | mitigate | `assertTableExists` on every `AI_AGENT_*` table is the direct check; if plan 04's host-include edit didn't take effect, the assertion fails. |
| T-02-10-06 | Elevation of Privilege | Row-level policy test passes because user "bob" wasn't actually assigned the row-level role | mitigate | Setup step explicitly assigns `AiAgentUserRole` + `AiAgentUserRowLevelRole` to both alice and bob (via `UserRepository` bean or jmix-app sample data); without both, the positive-alice branch also fails. |
| T-02-10-07 | Denial of Service | pgvector changeset accidentally runs on HSQLDB | mitigate | `assertTableAbsent("AI_AGENT_KB_VECTOR_STORE")` is a direct negative assertion; failure signals plan 06's `dbms="postgresql"` + preCondition gating regressed. |
