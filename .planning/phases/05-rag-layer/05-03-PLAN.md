<objective>
Build the asynchronous ingestion pipeline that transforms an uploaded AiKnowledgeDocument (status=PENDING) into READY, populating the pgvector store with chunks carrying role-scoped metadata. Status transitions commit independently of the caller so the HTTP/UI thread returns immediately after `/upload`. Retries are delegated to Spring AI's built-in `spring.ai.retry.*` controls (D-16, per RESEARCH override).

Purpose: satisfy RAG-01 (ingestion reaches READY within N seconds) and RAG-03 (failures capture a user-readable error message and leave status=FAILED atomically — no partial vectors).

Output: IngestionStatusWriter (REQUIRES_NEW), CancellationRegistry, AsyncIngestionWorker, MdcPropagatingTaskDecorator, aiAgentIngestExecutor bean registered in AIConfiguration, tuned defaults in application.properties.
</objective>

      2. Load document (read-only DataManager.load) — if missing, log warn, return.
      3. If cancellationRegistry.isCancelled(documentId) at any checkpoint → ingestionStatusWriter.markCancelled(documentId); cancellationRegistry.clear(documentId); return.

      7. Enrich every chunk's metadata:

         - `ChunkMetadata.DOCUMENT_ID` → document.id.toString()
         - `ChunkMetadata.EMBEDDING_MODEL` → value from `AiAgentEmbeddingProperties` (injected)
         - `ChunkMetadata.ALLOWED_ROLES` → `List<String>` copy of document.getAllowedRoles()

      8. Poll cancellation before each `vectorStore.add(batch)` call. Batch size = splitter.chunkSize-independent; use fixed batch of 32 chunks per add() call to bound memory.
